# Archived case study patients (first set of five)

Betsy Ross (hip fracture), Taylor Morgan (heart failure with ESRD), Rosa Delgado (total knee replacement), Walter Jennings (diabetic foot infection) and Eleanor Whitcomb (stage 4 pressure injury).
Each folder keeps its patient file, answer key authoring script, content.json and built Word/PDF packets. They are not listed in the Pre-Built Patients or Case Studies menus any more.
To bring one back, move its folder back into `casestudy/cases/` and run `python3 casestudy/make_index.py` and `node tools/make-prebuilt.js`.
New case study patients are being built one at a time, very thoroughly, in `casestudy/cases/`.
