# Archived LPN med-pass patients

Harold Bennett (hypertension), Maria Santos (cellulitis), Dorothy Hughes (fall with UTI) and Calvin Reed (type 2 diabetes): the first four LPN med-pass patients (PO + SubQ + IM). They are not in the Pre-Built Patients menu any more; the files are kept here.
To bring one back, remove `archived: true` from its line in `tools/make-prebuilt.js` and run `node tools/make-prebuilt.js`.
